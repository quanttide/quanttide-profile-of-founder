# work 事项台账

> `work/` 收**推动中事项的对象档案**：回答「这条工作线做了什么决定、依据是什么、下一步是什么」。与 `think/`（认知档案：怎么想、怎么应对、想到什么程度）分工——台账快变、允许过期关闭，只记日志里有证据的决定与判断；认知应对与价值仍归 `think/`，两边互链不重复。一事项一 `md`（现状 / 依据 / 下一步），不配 `lino` / `ttl`——态射是认知语言，台账不需要图谱。

## 边界

- 只收有日志证据的决定与判断（来源以各档标注为准，跨线事项可能出自 `default` 日志）；想法漫谈留在 `journal/`。
- 认知挂起点（方法未接价值、链未接情境）留在 `think/` 事情卡的「未决」；事实性行动项在这里。
- 事项关闭后不删档，状态改「已关闭」并在「现状」记结论。
