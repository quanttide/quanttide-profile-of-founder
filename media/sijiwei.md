# 肆季味

## 文案

最近来试了这家「肆季味」。

进门第一感觉是舒服：木质装修、暖光灯带、绿植点缀，
店员穿着统一的绿色工作服，店里大概三四个人在忙。
墙上写着「四时风物，季季皆有至味」，
定位是「融合新中餐」，一顿饭吃到了云贵泰几种风味。

点的是六道菜：

🍳 泰式打抛饭
肉碎铺得满满一层，中间一颗溏心蛋，旁边配了黄瓜片。
拌开之后[补口感：酱汁咸鲜/微辣/罗勒香气明显]。

🐔 黔香脆饼烧金爪
这盘是视觉最特别的，鸡爪、黄豆、脆饼一起炖得很入味。
[补口感：软糯脱骨 / 脆饼吸汁 / 辣度如何]。

🐟 苗寨百香酸汤鱼片
红汤很开胃，鱼片嫩，加了百香果和柠檬，酸得清爽。
[补口感：刺多不多 / 汤底是否适合泡饭]。

🦑 云南山菌炒鲜鱿
菌子和鱿鱼都炒得很干爽，[补口感：镬气/辣度]。

🥬 XO酱炒油麦菜
套餐里的素菜，油麦菜脆嫩，XO酱提鲜，正好解腻。

🍵 百香蜂蜜柚子茶
装在玻璃茶壶里，[补口感：甜度/是否解辣]。
