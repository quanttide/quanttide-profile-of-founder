# code 分区：AI 协作档案

> `code/` 收**与 AI 协作时反复出现的差**：回答「我以为 AI 知道什么、它实际做了什么、下次该用什么话把它拉回来」。与 `think/`（认知：怎么想）、`work/`（台账：做了什么决定）分工——这里只收协作层面的差与对应话术，不记业务事实、不记情绪。

## 口径

档案的来源是澄清账本（`qtfounder-lab` 的 `clarify.json` 与 `rules.md`）：账本是逐条原始记录，档案是提炼后的类型。按出现次数分三档，取已到的最高档：

1. **观察**：只出现过 1 次，先记形态，不急着下判断；
2. **类型**：同一类差出现 ≥2 次，说清「原以为 X，实际 Y」并配上一句该用的提示词；
3. **规则**：用户点头落进 `rules.md` 的那句原话，档里只引用不重写。

原始条目以 `clr_` id 指回账本，档案不复制原文——同一事实只在一处展开，账本仍是唯一事实源。

## 边界

- 主题来自「实际做了什么」这一列，不按日期、不按命令切档。
- 单次出现且不成类型的差留在账本，不建档。
- 不生成规则文本；`rules.md` 只读。
