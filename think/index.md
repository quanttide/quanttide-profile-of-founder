# think 档案框架（按事情重组）

## 蒸馏程度

一件事的思考在档案里能走到四层，取已到达的最高层：

1. **想法**——只在日志或散点，未入档案；
2. **情境**——触发点 / 事件与情绪已档案化；
3. **方法**——有了应对，且带适用条件；
4. **价值**——定型为价值判断，长出排除形态。
