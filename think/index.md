# think 档案框架（按事情重组）

> 原 `think/`（按情境）与 `work/`（按事件）合并，按**事情**重组——一个事情一组，回答「我在思考或推动哪些事情」「某件事思考到什么程度了」；情境（触发点）与事件作为条目挂在事情下，情绪 / 方法 / 价值随条目走，事情卡记蒸馏程度。条目原文不改，原文基线 `git show fe651c1:think/…`、`git show fe651c1:work/…`；更早五轴基线 `git show f4013d1:default/…`、`git show 86e8532:work/…`。一事情一组，每组三种格式——`.md` 状态与条目原文、`.lino` 链接记法（一行一条边）、`.ttl` 图谱节点与态射；本体与跨组边集中在本组 `index.*`。本目录收认知档案（怎么想、怎么应对）；事项台账（做了什么、下一步）见 [`../work/index.md`](../work/index.md)。

## 蒸馏程度

一件事的思考在档案里能走到四层，取已到达的最高层：

1. **想法**——只在日志或散点，未入档案；
2. **情境**——触发点 / 事件与情绪已档案化；
3. **方法**——有了应对，且带适用条件；
4. **价值**——定型为价值判断，长出排除形态。
