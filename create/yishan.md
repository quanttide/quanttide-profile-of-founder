# 忆山红

## 标题

辣椒铺满一整锅的江西小馆

## 文案

听说有家江西小馆把「鲜得很霸道」直接写在灯箱上，周末去试了试。红黑搪瓷盘、木桌红凳、草帽吊灯，明档厨房一路飘香，墙上挂着「赣鄱好味」的画。

点了五道菜：

- 剁椒鱼头：双耳金属锅端上来还在咕嘟，剁椒铺满整锅，红得发亮。拨开辣椒，鱼肉嫩，是地地道道的江西辣，鲜辣直冲天灵盖，配米饭一绝。
- 砂锅豆腐：瓦罐里炖着，豆腐吸饱豆豉和肉末的酱香，汤汁浓，下饭。
- 辣炒花甲：花甲干净无沙，红汤裹着每个壳，鲜辣开胃。
- 外婆菜炒蛋：搪瓷盘装着，外婆菜咸香配鸡蛋和青红椒粒，很费米饭的一道。
- 瓦罐肉饼汤：一人一罐，肉饼嫩、汤清鲜，辣到不行时来一口刚好解辣。

整体是真·江西辣，不能吃辣的慎点；上菜快，木桌红凳坐得舒服。人均价位和排队情况下次补。
