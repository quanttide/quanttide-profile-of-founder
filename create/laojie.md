# 老街

## 标题

甜口不辣的土徽菜，香酥鲈鱼是招牌

## 文案

最近在城南金鹏玖玖广场发现一家土徽菜，门头写着「忠都老街土徽菜」，招牌是「山里菜·原生态」。套餐整体偏甜口、不辣，适合不吃辣的搭子。

环境走典雅现代路线：红灯笼一排排挂着，藤编靠背椅配木色卡座，墙上挂着花枝装饰，饭点坐得挺满。

点的是双人套餐，五道菜配米饭：

- 香酥鲈鱼：整条鲈鱼躺在方形烤盘里，浇汁没过半身，铺着蒜子、青红椒。鱼先炸后浇汁，外皮吸汁之后依然酥，口味偏甜鲜，基本没有辣度。整顿吃下来最爱的一道。
- 宫保鸡丁：花生米给得大方，鸡丁滑嫩，酸甜口，不辣，下饭。
- 老街炖豆腐：豆腐炖出蜂窝，吸满肉末和豆豉的汤汁，滚烫上桌，撒着葱花，很家常。
- 蒜子焖青茄子：青茄子焖得软烂，蒜香出头，酱汁浓稠挂壁，微甜解腻。
- 西湖牛肉羹：青花大碗装着，牛肉末、蛋花、豆腐丝给得足，咸鲜温和，饭后一碗很舒服。

整体口味统一走甜鲜路线，几乎没有辣度，分量足。地址在城南金鹏玖玖广场，适合带不能吃辣的家人一起来。
